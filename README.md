# Drowsiness Detection Based on Facial Images

## Deskripsi
Project ini merupakan implementasi Pengolahan Citra dan Visi Komputer (PCVK) untuk mendeteksi indikasi kantuk seseorang berdasarkan citra wajah.

Sistem menganalisis karakteristik wajah, terutama area mata dan kantung mata, untuk mengidentifikasi indikasi kondisi mengantuk atau tidak mengantuk.
